# Smart Grids

Status: computational companion implemented

This package provides reproducible smart-grid examples for the eleventh article in the Sustainable Catalyst Energy Systems series.

## Included methods

- Smart-meter interval demand analysis
- Load factor
- Managed electric-vehicle charging
- Demand response
- Volt/VAR energy-reduction example
- FLISR customer-hour restoration benefit
- Communications redundancy
- DER aggregation and dispatchability
- Flexible-peak uncertainty analysis
- Python, R, Julia, C, and SQL cross-checks
- Machine-readable CSV and JSON outputs
- Dependency-free SVG restoration visualization

## Run

```bash
./run_all.sh
```

The core workflow requires Python 3.10 or later and uses only the Python standard library. Optional R, Julia, C, and SQLite checks run when installed.

## Scope

All data are synthetic teaching examples. The package illustrates smart-grid concepts and does not replace utility-grade ADMS, DERMS, protection, communications, cybersecurity, or distribution power-flow studies.
